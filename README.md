# Příjmový potenciál dlužníka API Wrapper

This is a Rust library that provides a wrapper for the API used by the [Nástroj pro výpočet příjmového potenciálu dlužníka](https://msp.gov.cz/web/insolvence/nastroje/prijmovy-potencial-dluznika) by the Ministry of Justice of the Czech Republic. 

This library alllows for type-safe calling of the API endpoints and deserialization of the responses into Rust structs.
